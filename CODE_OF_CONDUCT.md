# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and discussions. Harassment, insults, personal attacks, sexualised language and publishing others' private information are not acceptable.

## Scope

It applies to all project spaces on GitHub (issues, pull requests, discussions) and to anyone representing the project elsewhere.

## Enforcement

Report unacceptable behaviour privately to the maintainer, [@KROU4](https://github.com/KROU4). Reports are reviewed promptly and kept confidential.

The maintainer may remove comments, commits or other contributions, and may temporarily or permanently ban contributors whose behaviour violates this code, following the enforcement guidelines of the Contributor Covenant 2.1.
